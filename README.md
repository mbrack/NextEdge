# NextEdge

[Deutsch](#deutsch) · [English](#english)

## Deutsch

Element-Simulator für Eiskunstlauf: Sprünge, Pirouetten, Schritte und Spezialelemente als 3D-Animation mit Kanten, Flugbahn, Stellgrössen, Trainingstipps, Videos und persönlichen Notizen.

Die Seite ist eine einzelne Datei (`index.html`) ohne Build-Schritt. three.js wird vom CDN cdnjs geladen.

### Live

Über GitHub Pages: https://mbrack.github.io/NextEdge/

Die Kamera für die Referenzhaltung funktioniert nur über diese https-Adresse, nicht beim Öffnen der Datei vom Gerät.

### Hinweis

Hilfe ohne Gewähr. Verbindlich sind die offiziellen Reglemente von ISU, Swiss Ice Skating und dem jeweiligen Veranstalter. Die Körperposen sind noch nicht von einer Trainerin geprüft.

## English

Element simulator for figure skating: jumps, spins, steps and special moves as 3D animations, with edges, flight path, adjustable parameters, training tips, videos and personal notes.

The page is a single file (`index.html`) with no build step. three.js is loaded from the cdnjs CDN. The user interface is in German.

### Live

On GitHub Pages: https://mbrack.github.io/NextEdge/

The camera for the reference pose only works through this https address, not when the file is opened directly from the device.

### Disclaimer

Provided without warranty. The official regulations of the ISU, Swiss Ice Skating and the respective event organiser are binding. The body poses have not yet been reviewed by a coach.
